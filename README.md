# myPills

**myPills** — простое приложение для управления хранением таблеток. Работает как настоящее приложение на iPhone (PWA) — можно установить на экран «Домой» и использовать без интернета.

## 🌐 Приложение

[Открыть myPills](https://mmogers.github.io/myPills/)

## 📋 Возможности

- Добавление лекарств
- Категории
- Указание срока годности
- 📱 Установка на экран «Домой» на iPhone (как приложение, без Safari)
- 📴 Работает без интернета после установки
- 💾 Данные хранятся локально на устройстве

## 📲 Установка на iPhone

1. Открой ссылку выше в **Safari**
2. Нажми «Поделиться» → «На экран Домой»
3. Готово — иконка появится на рабочем экране

## 🚀 GitHub Pages

Приложение опубликовано с помощью GitHub Pages и работает как Progressive Web App (PWA).
